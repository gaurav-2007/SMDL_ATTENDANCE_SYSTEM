1. Local Environment & Execution Setup

   - Replaced flaky nodemon reloader with Node 24's high-performance native live watcher (`node --watch src/index.js`).
   - Cleaned and updated `.gitignore` to prevent dev shims and environment files from leaking.

2. Authentication Bug Fix (Admin Demo Login Resolution)
   - Issue: When attempting admin demo login, the screen threw "Login failed. Check credentials".
   - Root Cause:
     * Backend returned response format: { success: true, data: { ...user, token } }.
     * Frontend `AuthContext.jsx` looked for `data.data.user` (which was undefined).
     * In `LoginPage.jsx`, reading `loggedUser.name` triggered a JavaScript runtime TypeError (`Cannot read properties of undefined`).
     * Catch block intercepted this and showed generic "Login failed. Check credentials".
   - Fixes Implemented:
     * Updated `buildUserResponse` in `authController.js` to return both `...user` and nested `user` properties.
     * Updated `AuthContext.jsx` to safely parse `data?.data?.user || data?.data`.
     * Added `admin` shorthand support so typing either `admin@smdl.ac.in` or `admin` works.
     * Added trim & lowercase normalization to email inputs.
     * Enhanced `LoginPage.jsx` with an interactive 1-Click Demo card featuring "Auto-fill" and "⚡ Instant Login" buttons.
     * Eliminated React render-time navigation warning using `<Navigate />`.

3. Student & Teacher Registration Bug Fix (Name undefined error)
   - Issue: When creating a student or teacher account, error occurred:
     "name Invalid input: expected string, received undefined".
   - Root Cause:
     * Frontend `RegisterPage.jsx` form state used field `full_name`.
     * Backend Zod validator strictly expected `name: z.string()`.
     * When submitting, `name` was missing/undefined, triggering Zod validation rejection.
   - Fixes Implemented:
     * Updated `RegisterPage.jsx` `handleSubmit` to provide both `name` and `full_name` in payload.
     * Updated `validators.js` on backend to accept `name` or `full_name` gracefully.
     * Added empty phone string handling in Zod schema so optional phone doesn't fail regex.
     * Allowed optional academic fields (`class`, `division`, `course_id`, `division_id`).
     * Updated `authController.js` `registerStudent` & `registerTeacher` to safely extract and store user names.
     * Verified both Student and Teacher registration flows via automated end-to-end tests (HTTP 201 Created).

4. Implemented & Working Modules
   - Full Authentication Engine (JWT signing, bcrypt password hashing, token verification).
   - Multi-role Routing & Route Protection (`ProtectedRoute.jsx` for Admin, Teacher, Student).
   - Role-based redirect on root path (`/` redirects to `/admin`, `/teacher`, or `/student`).
   - Admin Teacher Approval System:
